# 🔄 Настройка автообновления

## Что реализовано

Автообновление через GitHub Releases:
- ✅ Проверка версии при запуске (через 2 сек после открытия)
- ✅ Красивый диалог с прогресс-баром
- ✅ Скачивание в фоне
- ✅ Автоматическая установка
- ✅ Откат при ошибке

## Настройка

### 1. Создай GitHub репозиторий

1. Зайди на https://github.com/new
2. Название: `pomoshnik`
3. Public или Private
4. Нажми **Create repository**

### 2. Настрой репозиторий

В файле `utils/updater.py` измени:

```python
# Строка 16
GITHUB_REPO = "твой_ник/pomoshnik"  # owner/repo
```

### 3. Опубликуй код

```bash
cd C:\Users\kot35\IdeaProjects\pomoshnik
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/твой_ник/pomoshnik.git
git push -u origin main
```

### 4. Создай первый релиз

1. Зайди на https://github.com/твой_ник/pomoshnik/releases/new
2. Tag: `v1.0`
3. Title: "Версия 1.0"
4. Description: "Первый релиз"
5. Прикрепи файл `installer/Помощник_установщик_1.0.exe`
6. Нажми **Publish release**

### 5. Пересобери приложение

```bash
pyinstaller --clean Pomoshnik.spec
```

## Как работает

### При запуске:
1. Приложение ждёт 2 секунды
2. Отправляет запрос на GitHub API
3. Сравнивает текущую версию с последней

### Если новая версия есть:
```
┌─────────────────────────────────┐
│  Доступно обновление!           │
│  🎉                            │
│  Версия 1.1 (01.01.2025)       │
│                                 │
│  Что нового:                    │
│  • Исправлены ошибки            │
│  • Добавлена печать             │
│                                 │
│  [Установить]  [Позже]          │
└─────────────────────────────────┘
```

### При нажатии "Установить":
1. Скачивается `Помощник_установщик_1.1.exe`
2. Прогресс-бар показывает скорость
3. После скачивания — автозапуск установщика
4. Приложение закрывается

### Если обновлений нет:
```
┌─────────────────────────────────┐
│  Всё обновлено!                 │
│  ✅                            │
│  У вас последняя версия 1.0     │
│                                 │
│              [OK]               │
└─────────────────────────────────┘
```

## Формат CHANGELOG

В описании релиза используй:

```markdown
## Что нового в 1.1
- ✅ Добавлена печать (Ctrl+P)
- ✅ Экспорт в DOCX
- ✅ Исправлена подсветка рифм
```

## Версионирование

Используй семантическое версионирование:
- `1.0` → `1.1` → `1.2` (маленькие обновления)
- `1.0` → `2.0` (большие изменения)

## Отладка

Если проверка не работает:
1. Проверь подключение к интернету
2. Проверь `GITHUB_REPO` в `utils/updater.py`
3. Открой консоль — там есть логи `[Updater]`
