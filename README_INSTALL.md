# Помощник для написания песен — Установочный файл

## 📦 Что включено
- `Помощник.exe` — полностью автономное приложение (60 МБ)
- Встроенные словари рифм и шаблоны
- Темная тема оформления

## 🚀 Установка
1. Скопируйте папку `dist` на рабочий стол или в удобное место
2. Запустите `Помощник.exe`
3. Программа готова к работе — ничего устанавливать не нужно

## 💾 Где сохраняются данные
Песни сохраняются в подпапках рядом с исполняемым файлом:
- `storage/songs/` — сохраненные песни
- `storage/versions/` — история версий

**Важно:** При перемещении `.exe` папки `storage` перемещается вместе с ним.

## 🎨 Возможности
- Поиск рифм по слову и окончанию
- Шаблоны для разных жанров (поп, рок, рэп, баллада, инди, шансон)
- Редактор с AI-подсказками
- Библиотека фраз и метафор
- Экспорт в TXT и PDF
- История версий песен

## ⚠️ Примечание
При первом запуске Windows может показать предупреждение безопасности.
Нажмите "Подробнее" → "Все равно запустить".
