# 🚀 Настройка автообновления через GitHub

## ✅ Что уже готово

Приложение **уже поддерживает автообновление**:
- ✅ Проверка версии при запуске (через 2 секунды)
- ✅ Красивый диалог с прогресс-баром
- ✅ Автоматическое скачивание и установка
- ✅ Откат при ошибке

## 📋 Шаг 1: Создай GitHub репозиторий

1. Открой https://github.com/new
2. **Repository name**: `pomoshnik`
3. **Description**: `Помощник для написания песен`
4. Выбери **Public** или **Private**
5. **НЕ** отмечай "Initialize this repository with a README"
6. Нажми **Create repository**

## 📝 Шаг 2: Настрой адрес репозитория

Открой файл `utils/updater.py` и измени строку 16:

```python
# БЫЛО:
GITHUB_REPO = "kot35/pomoshnik"

# СТАЛО (замени на свой ник!):
GITHUB_REPO = "твой_ник/pomoshnik"
```

## 💻 Шаг 3: Опубликуй код в GitHub

Открой **PowerShell** и выполни команды по очереди:

```powershell
# Перейди в папку проекта
cd C:\Users\kot35\IdeaProjects\pomoshnik

# Инициализируй Git (если ещё не сделано)
git init

# Добавь все файлы
git add .

# Создай первый коммит
git commit -m "Initial commit: Помощник для написания песен v1.0"

# Переименуй ветку в main
git branch -M main

# Добавь удалённый репозиторий (замени на свой ник!)
git remote add origin https://github.com/твой_ник/pomoshnik.git

# Отправь код в GitHub
git push -u origin main
```

> ⚠️ **Если Git не установлен:** Скачай с https://git-scm.com/download/win

## 🎉 Шаг 4: Создай первый релиз

1. Открой https://github.com/твой_ник/pomoshnik/releases/new
2. **Tag version**: нажми "Choose a tag" → напиши `v1.0` → "Create new tag"
3. **Release title**: `Версия 1.0`
4. **Describe**:
   ```
   Первый релиз Помощника для написания песен

   ## Что реализовано:
   - ✅ Редактор песен с автоподсказками
   - 🔤 Словарь рифм (~60 слов, ~500+ рифм)
   - 📚 Библиотека фраз (~150+ фраз по категориям)
   - ✍️ AI-генерация стихов (AABB/ABAB)
   - 📄 Экспорт в PDF и TXT
   - 🎨 Тёмная и светлая тема
   - 💾 Автосохранение
   - 🔄 Автообновление
   ```
5. **Прикрепи файл**: перетащи `installer/Помощник_установщик_1.0.exe` в окно или нажми "attach binaries"
6. Нажми **Publish release**

   ```

   ```

## 🆕 Как выпустить обновление

### 1. Внеси изменения в код

### 2. Обнови версию в `utils/updater.py`:
```python
APP_VERSION = "1.1"  # Было "1.0"
```

### 3. Закоммить и отправь:
```powershell
git add .
git commit -m "Версия 1.1: новые функции"
git push
```

### 4. Пересобери:
```powershell
pyinstaller --clean Pomoshnik.spec
.\build.ps1
```

### 5. Создай новый релиз на GitHub:
- Tag: `v1.1`
- Title: `Версия 1.1`
- Прикрепи новый `installer/Помощник_установщик_1.1.exe`

## 🐛 Решение проблем

### Ошибка "Network error"
- Проверь подключение к интернету
- Проверь `GITHUB_REPO` в `utils/updater.py`
- Открой консоль — там логи `[Updater]`

### Ошибка "Invalid JSON response"
- GitHub ограничивает запросы без авторизации
- Добавь токен (см. GitHub API docs)

### Релиз не найден
- Убедись, что tag начинается с `v` (например `v1.0`)
- Убедись, что прикреплён `.exe` файл
- Проверь, что релиз опубликован (не Draft)

## 📊 Версионирование

Используй **семантическое версионирование**:
- `1.0` → `1.1` → `1.2` — маленькие обновления (багфиксы)
- `1.0` → `2.0` — большие изменения (новые функции)
- `0.1` → `0.2` — альфа-версии (разработка)

## 🔐 Для private репозитория

Если репозиторий private, добавь токен в `utils/updater.py`:

```python
def check_for_updates(timeout: int = 10) -> Optional[dict]:
    try:
        req = urllib.request.Request(
            GITHUB_API_URL,
            headers={
                "Accept": "application/vnd.github.v3+json",
                "User-Agent": f"{APP_NAME}-Updater/{APP_VERSION}",
                "Authorization": f"token ВАШ_ТОКЕН"  # Добавь сюда
            }
        )
        # ... остальной код без изменений
```

Токен создай на: https://github.com/settings/tokens
