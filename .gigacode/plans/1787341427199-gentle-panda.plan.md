# План миграции на PyQt6

## Обзор текущего приложения
**Pomoshnik** — Streamlit-приложение для написания песен с 6 страницами:
- **Главная** — карточки возможностей, популярные слова, статистика
- **Рифмы** — поиск по слову/окончанию, популярные слова
- **Шаблоны** — выбор жанра (поп, рок, рэп, баллада, инди, шансон)
- **Редактор** — пошаговый редактор песен с секциями, подсчётом слогов, рифмами, версиями
- **Фразы** — библиотека метафор по категориям
- **Мои песни** — список/загрузка/удаление сохранённых песен

**Backend-модули** (без изменений): `engine/rhymes.py`, `engine/structure.py`, `engine/editor.py`, `engine/history.py`, `engine/phrases.py`, `engine/syllable_counter.py`, `utils/export.py`

**Данные**: `data/rhymes_dict.json`, `data/templates.json`

### Ключевые решения
1. **QStackedWidget** — все страницы в одном окне, переключение через sidebar
2. **QSS (Qt Style Sheets)** — тёмная тема, аналог CSS, стилизует все виджеты
3. **Чистый Python код** — никаких .ui файлов, вся логика в Python
4. **Минимальные изменения бэкенда** — модули `engine/` и `utils/` без изменений
5. **Модальные диалоги** — для экспорта, подтверждения удаления

## Пошаговый план

### Этап 1: Скелет приложения и тёмная тема
- [ ] Создать `ui/` пакет с `__init__.py`
- [ ] Создать `ui/pages/` пакет с `__init__.py`
- [ ] Создать `ui/components/` пакет с `__init__.py`
- [ ] Создать `assets/qss/dark_theme.qss` — полная тёмная тема (аналог CSS)
- [ ] Создать `ui/main_window.py` — QMainWindow с:
  - Sidebar слева (QListWidget или QVBoxLayout с QPushButton)
  - QStackedWidget по центру для страниц
  - Разделитель sidebar/content
- [ ] Создать `app.py` — точка входа

### Этап 2: Home page
- [ ] `ui/pages/home_page.py` — QWidget с:
  - Заголовок (QLabel с gradient text аналогом)
  - 3 карточки-кнопки (Рифмы, Шаблоны, Редактор)
  - Популярные слова — сетка QPushButton
  - Статистика — 3 stat card (QLabel)

### Этап 3: Rhymes page
- [ ] `ui/pages/rhymes_page.py` — QWidget с:
  - QTabWidget (3 вкладки: По слову, По окончанию, Популярные)
  - Tab 1: QLineEdit + QSlider + QPushButton → QListWidget с результатами
  - Tab 2: QLineEdit + QSlider + QPushButton → QListWidget
  - Tab 3: QListWidget с популярными словами

### Этап 4: Templates page
- [ ] `ui/pages/templates_page.py` — QWidget с:
  - Сетка карточек жанров (QGridLayout с QPushButton в каждой)
  - 3 колонки, одинаковая высота
  - Кнопка "Выбрать" → переход в редактор

### Этап 5: Editor page (самый сложный)
- [ ] `ui/pages/editor_page.py` — QWidget с пошаговым wizard:
  - **Шаг 1**: Выбор жанра (QComboBox) → переход к шагу 2
  - **Шаг 2**: Ввод названия (QLineEdit) → переход к шагу 3
  - **Шаг 3**: Редактор секций:
    - Progress bar (QProgressBar)
    - QListWidget/QTreeWidget с раскрывающимися секциями
    - Каждая секция: QPlainTextEdit + статистика слогов + QLabel tips
    - Рядом QLabel с рифмами-кнопками
  - **Кнопки внизу**: Сохранить, Сохранить версию, Экспорт, Удалить
  - **Статистика**: статические QLabel после сохранения
  - **История версий**: QListWidget с кнопками Restore/Compare

### Этап 6: Phrases page
- [ ] `ui/pages/phrases_page.py` — QWidget с:
  - QTabWidget (3 вкладки: Категории, Поиск, Случайные)
  - Tab 1: QComboBox (категории) + QListWidget с фразами
  - Tab 2: QLineEdit + QListWidget результатов
  - Tab 3: QSlider + QComboBox + QPushButton → QListWidget

### Этап 7: Songs page
- [ ] `ui/pages/songs_page.py` — QWidget с:
  - QListWidget с карточками песен (каждый item — кастомный виджет)
  - Кнопки: Открыть, Экспорт, Удалить
  - Пустое состояние с кнопкой "Создать песню"

### Этап 8: Экспорт и интеграции
- [ ] Интегрировать `utils/export.py` — диалог с QRadioButton (TXT/PDF)
- [ ] Кнопка скачивания → QFileDialog для выбора пути
- [ ] Обработка ошибок (QMessageBox)

### Этап 9: Финальная настройка
- [ ] Обновить `requirements.txt`: удалить `streamlit`, добавить `PyQt6>=6.5.0`, `fpdf2>=2.7.9`
- [ ] Обновить `launch.bat` → запуск `python app.py`
- [ ] Обновить `.spec` для PyInstaller (добавить PyQt6 hooks)
- [ ] Тестирование всех страниц
- [ ] Удаление старых `_gen*.py`, `_s*.py` файлов
