# План: Помощник для написания песен (Web-приложение на Streamlit)

## Обзор
Создание веб-приложения для помощи в написании песен с интерфейсом на Streamlit.

## Функциональность

### 1. Подсказки по рифмам
- Ввод слова → генерация списка рифм
- Поиск рифмованных слов по окончанию
- Фильтрация по количеству слогов

### 2. Структура песни
- Шаблоны структуры (Куплет-Припев-Куплет-Припев)
- Подсказки по размеру строки
- Советы по ритмике

### 3. Редактор текста песни
- WYSIWYG-редактор с разделением на секции
- Автосохранение в JSON
- Экспорт в TXT/PDF
- История версий

## Техническая архитектура

### Стек
- **Фреймворк:** Streamlit (Python)
- **Хранение:** Локальные JSON файлы
- **Доп. библиотеки:** `textblob` для анализа текста, `fpdf2` для экспорта

### Структура проекта
```
pomoshnik/
├── app.py                    # Основной файл Streamlit
├── requirements.txt          # Зависимости
├── engine/
│   ├── rhymes.py             # Логика рифм
│   ├── structure.py          # Шаблоны структуры
│   └── editor.py             # Функции редактора
├── data/
│   ├── rhymes_dict.json      # Словарь рифм
│   └── templates.json        # Шаблоны песен
├── storage/
│   └── songs/                # Сохранённые песни (JSON)
└── utils/
    └── export.py             # Экспорт в TXT/PDF
```

## Реализация

### Шаг 1: Настройка проекта
- Создать `requirements.txt`
- Создать структуру директорий

### Шаг 2: Движок рифм (`engine/rhymes.py`)
- Загрузка словаря рифм из JSON
- Функция `get_rhymes(word)` → список рифм
- Функция `get_rhymes_by_ending(ending)` → рифмы по окончанию
- База рифм: ~500+ популярных русских слов

### Шаг 3: Шаблоны структуры (`engine/structure.py`)
- Определяемые шаблоны:
  - Поп: Куплет (4) → Припев (4) → Куплет (4) → Припев (4)
  - Баллада: Куплет (6) → Припев (4) → Куплет (6)
  - Рэп: Куплет (16) → Припев (8) → Куплет (16)
- Функция `get_template(style)` → структура с подсказками

### Шаг 4: Редактор (`engine/editor.py`)
- Создание новой песни с названием и стилем
- Добавление секций (куплет, припев, бридж)
- Автосохранение в `storage/songs/`
- Загрузка сохранённых песен
- Экспорт в TXT и PDF

### Шаг 5: UI Streamlit (`app.py`)
- Боковое меню с навигацией:
  - 🎵 Рифмы
  - 📝 Редактор
  - 💾 Мои песни
  - 📚 Шаблоны
- Вкладка "Рифмы": поиск + результаты
- Вкладка "Редактор": поля для каждой секции
- Вкладка "Мои песни": список + загрузка/удаление
- Вкладка "Шаблоны": выбор стиля + описание

### Шаг 6: Экспорт (`utils/export.py`)
- Экспорт в TXT с форматированием
- Экспорт в PDF через `fpdf2`

## Проверка
1. Запуск: `streamlit run app.py`
2. Тест рифм: ввод слова → проверка результатов
3. Тест редактора: создание песни, сохранение, загрузка
4. Тест экспорта: экспорт в TXT и PDF
5. UI/UX проверка: удобство навигации
