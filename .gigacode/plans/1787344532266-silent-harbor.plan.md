# План разработки редактора песен

## Цель
Создать пошаговый мастер редактора песен с редактированием секций, подсказками и навигацией.

## Архитектура

### Создаваемые файлы:
1. **`ui/pages/editor_page.py`** — основной компонент редактора

### Модифицируемые файлы:
1. **`ui/main_window.py`** — добавление editor_page в stacked widget
2. **`ui/pages/home_page.py`** — метод `_set_search_word` для навигации

---

## Реализация `editor_page.py`

### Класс: `EditorPage(QWidget)`

#### Состояния редактора:
- `empty_state` — начальный экран с кнопкой "Создать песню"
- `editing_mode` — свободное редактирование секций

#### Основные компоненты UI:

**1. Верхняя панель:**
- Заголовок песни (редактируемый QLabel/QLineEdit)
- Индикатор прогресса (progress bar или stepped indicator)
- Статистика (заполнено N/M секций, строк, рифм)

**2. Навигация по секциям (боковая панель 220px слева):**
- Список всех секций с метками ("Куплет 1", "Припев 1" и т.д.)
- Визуальная индикация заполненности (✓ если текст введён)
- Кликабельные элементы для быстрого перехода к секции
- Текущая секция выделена акцентным цветом

**3. Область редактирования (центр):**
- QTextEdit для ввода текста секции
- Индикатор типа секции (🎤 Куплет, 🔊 Припев и т.д.)
- Счётчик строк и слогов (live)
- Подсказки из templates.json (блок сверху или снизу)

**4. Панель AI-подсказок (правая боковая панель 250px или нижняя):**
- Переключатель: "Статические" / "AI" / "Обе"
- Статические: tips из templates.json
- AI: рифмы к последнему слову строки, случайные фразы из engine/phrases.py
- Кнопка "Вставить" для добавления подсказки в текст

**4. Кнопки навигации:**
- ← Назад / Далее →
- Сохранить (на последней секции или всегда доступна)
- Отмена (с подтверждением)

#### Методы:

```python
class EditorPage(QWidget):
    Signal: text_changed, song_saved, song_created
    
    def __init__(self, page_key: str, parent=None)
    def _init_ui()
    def set_template(self, style_id: str) — вход с TemplatesPage
    def create_song_from_template(self, style_id: str, title: str)
    def go_to_section(self, section_index: int)
    def save_song(self) — ручное сохранение
    def _auto_save(self) — автосохранение с debounce (5 сек)
    def _update_progress()
    def _update_section_list()
    def _show_section_tips(section_data: dict) — статические подсказки
    def _generate_ai_suggestions() — AI-подсказки (рифмы + фразы)
    def _recalculate_stats()
    def _get_last_word(line: str) -> str — для поиска рифм
```

#### Логика работы:

1. **Вход с TemplatesPage:**
   - `set_template(style_id)` вызывается из TemplatesPage
   - Создаётся песня через `editor.create_song(title, style_id, template_context)`
   - UI переключается в `editing_mode`

2. **Свободное редактирование:**
   - Боковая панель с секциями слева (кликабельные)
   - Текущая секция выделена
   - Любую секцию можно открыть кликом
   - Прогресс-бар сверху показывает % заполненности

3. **Подсказки:**
   - Статические: tips из templates.json для текущей секции
   - AI: рифмы к последнему слову + случайные фразы из `engine/phrases.py`
   - Переключатель режимов подсказок

4. **Секции без текста (проигрыш, интро, аутро):**
   - Можно добавить заметки/комментарии
   - Не требуют текста, но подсчитываются в статистике

5. **Сохранение:**
   - Автосохранение при каждом изменении (debounce 5 сек)
   - Ручное сохранение по кнопке Ctrl+S
   - Сохранение через `editor.save_song(song)`

## Интеграция с `main_window.py`

```python
def __init__(self):
    # ... существующий код ...

    from ui.pages.home_page import HomePage

    self.add_page(HomePage("home"), "home")
    self.add_page(RhymesPage("rhymes"), "rhymes")
    self.add_page(TemplatesPage("templates"), "templates")
    self.editor_page = EditorPage("editor")  # НОВОЕ
    self.add_page(self.editor_page, "editor")
    self.add_page(PhrasesPage("phrases"), "phrases")
    self.add_page(QWidget(), "songs")  # Заглушка для будущих песен
```

## Детали UI

### Цветовая схема (из dark_theme.qss):
- Основной фон: #0f3460 / #16213e
- Акцент: #e94560
- Текст: #ffffff
- Карточки: #1f2b4d

### Типографика:
- Заголовки: QFont("Segoe UI", 16-24, Bold)
- Текст: QFont("Segoe UI", 12-14)
- Подсказки: QFont("Segoe UI", 11, italic)

### Размеры:
- QTextEdit: мин. 200px высота, растягивается
- Навигация по секциям: горизонтальная полоса или sidebar 200px width
- Прогресс бар: высота 8px
