## 🔧 Технические детали

### Стек технологий
- **Язык:** Python 3.14.7
- **GUI:** PyQt6 6.6+
- **Сборка:** PyInstaller + Inno Setup 7
- **Хранение:** JSON файлы
- **Обновления:** GitHub Releases API

### Горячие клавиши
- `Ctrl+E` — Открыть редактор
- `Ctrl+P` — Печать/Экспорт
- `Ctrl+F` — Поиск
- `Ctrl+S` — Сохранить (автосохранение)
